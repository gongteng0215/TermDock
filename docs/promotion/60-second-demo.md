# TermDock 60-Second Demo Script

[中文](60-second-demo.zh-CN.md)

Use this as the source for the README GIF, a short video, or a social post. Keep the recording focused on one clear promise: TermDock is a safer SSH + SFTP desktop workspace for small-team server operations.

## English Version

### Title

TermDock: a safer SSH + SFTP desktop workspace

### Shot List

| Time | Visual | Voiceover / Caption |
| --- | --- | --- |
| 0-5s | Open TermDock on the main workbench. | "TermDock brings SSH, SFTP, server health, and recovery tools into one desktop workspace." |
| 5-12s | Open or focus an SSH session tab. | "Connect to your server with a multi-tab terminal." |
| 12-22s | Show the SFTP file browser and transfer dock. | "Browse remote files and manage uploads or downloads without switching apps." |
| 22-32s | Trigger the dangerous-command approval bar. | "Risky commands are caught before they hit the server." |
| 32-42s | Open Retry Center. | "Failed transfers stay recoverable through the Retry Center." |
| 42-52s | Show Operation Center or server health panel. | "Check active operations and server health from the same workspace." |
| 52-60s | End on GitHub README / Releases link. | "Open source, local-first, available for Windows and macOS." |

### README GIF Notes

- Recommended capture size: 1440x920 or 1280x820.
- Keep credentials and real hosts out of frame.
- Prefer a fixture or demo server account.
- Keep the GIF under roughly 10 MB for README load speed.
