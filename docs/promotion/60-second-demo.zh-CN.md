# TermDock 60 秒演示脚本

[English](60-second-demo.md)

这份脚本可用于 README GIF、短视频或社交平台发布。录制时只聚焦一个清晰承诺：TermDock 是面向小团队服务器运维的安全 SSH + SFTP 桌面工作台。

## 标题

TermDock：更安全的 SSH + SFTP 桌面工作台

## 分镜

| 时间 | 画面 | 旁白 / 字幕 |
| --- | --- | --- |
| 0-5 秒 | 打开 TermDock 主界面。 | "TermDock 把 SSH、SFTP、服务器状态和故障恢复放进一个桌面工作台。" |
| 5-12 秒 | 打开或聚焦一个 SSH 会话标签页。 | "多标签终端，同时管理多台服务器。" |
| 12-22 秒 | 展示 SFTP 文件浏览器和底部传输区。 | "远程文件浏览、上传、下载不用来回切工具。" |
| 22-32 秒 | 触发危险命令审批栏。 | "危险命令执行前先拦一下，减少手滑风险。" |
| 32-42 秒 | 打开 Retry Center。 | "传输失败后保留记录，可以从重试中心恢复。" |
| 42-52 秒 | 展示 Operation Center 或服务器健康面板。 | "当前操作和服务器状态都在同一个工作台里。" |
| 52-60 秒 | 结尾展示 GitHub README / Releases。 | "开源、本地优先，支持 Windows 和 macOS。" |

## README GIF 建议

- 建议录制尺寸：1440x920 或 1280x820。
- 不要录入真实服务器地址、账号、密码或密钥路径。
- 优先使用测试服务器或 smoke fixture。
- README GIF 尽量控制在 10 MB 以内。
